2. Step-by-Step Calculator Configuration Guide (Services 1 – 3)

Configure each service in the official AWS Pricing Calculator (calculator.aws) using these exact field parameters:

1. Amazon CloudFront (Web CDN & Static Assets)

In calculator, search for: CloudFront

  • Option A: Using Flat-Rate Plans (as seen in calculator): In Pro Plan, enter 1 (leave Free, Business, Premium blank). Why? 100k users generate 3–5 TB of static bundle traffic. Pro Plan bundles higher bandwidth and edge protections at a flat rate. Estimated Cost: ~$15.00 – $25.00 / month.
  • Option B: Using Standard Usage Tier: Data Transfer Out: 4 TB per month | Requests: 15,000,000 HTTPS requests. Estimated Cost: ~$35.00 / month.

2. Amazon RDS for PostgreSQL (Primary HR Database)

In calculator, search for: Amazon RDS for PostgreSQL

  • Region: Asia Pacific (Mumbai) ap-south-1 (lowest latency for Indian workforce).
  • Deployment Option: Multi-AZ (Mandatory for enterprise HRMS: automatic failover so attendance & payroll never go down).
  • Instance Type: Family: Memory Optimized (db.r6g.xlarge or db.m6g.xlarge) | Specs: 4 vCPUs, 32 GiB RAM (Comfortably handles 100k records, complex payroll queries, and attendance locks).
  • Pricing Model: 1-Year Savings / On-Demand.
  • Storage: Storage Type: General Purpose SSD (gp3) | Amount: 1,000 GB (1 TB) | IOPS: 4,000 IOPS | Throughput: 250 MB/s.
  • Backup Storage: 1,000 GB (7-day automated backup retention).
  • Estimated Cost: ~$380.00 – $440.00 / month (Drops to ~$250/mo on 1-year reserved).

3. AWS ECS on Fargate (Backend API & Node.js Server)

In calculator, search for: Elastic Container Service → Choose Fargate

  • Operating System: Linux | Architecture: ARM64 (AWS Graviton — 20% cheaper and faster).
  • Workload Configuration: Number of Tasks: 4 base tasks, autoscaling to 8 during morning punch peak. Average running continuously: 5 tasks | vCPU per task: 2 vCPU | Memory per task: 4 GB RAM.
  • Hours per day: 24 | Days per month: 30.5 (~730 hours/month).
  • Application Load Balancer (ALB): Included: Number of ALBs: 1 | Processed bytes / LCUs: 15 LCUs.
  • Estimated Cost: ~$165.00 – $210.00 / month.

JOY PeopleHR — How "Pay-As-You-Go" Works on AWS
Automatic Scaling, Zero Upfront Risk & Detailed Billing Mechanics
Model: AWS On-Demand
Commitment: None (Second/GB granularity)

Pay-As-You-Go is AWS's default billing model. There are no contracts, no upfront payments, and no minimum monthly commitments. You are billed down to the exact second, gigabyte, or API request your SaaS actually uses. If your web and mobile app use 10 GB of storage this month, you pay for 10 GB ($0.23). If traffic surges during morning attendance and then drops in the evening, your servers automatically scale down and you stop paying for unused compute.

Pay-As-You-Go ensures you are never charged for idle compute.

7. How to Select "Pay-As-You-Go" in the AWS Pricing Calculator

When configuring services on calculator.aws:

  • For CloudFront: Instead of picking a paid Flat-Rate plan, select the Free Plan (or scroll down to the data transfer fields and enter your expected GB).
  • For RDS PostgreSQL & EC2/ECS Compute: Under Payment Options / Pricing Strategy, select:
    "On-Demand" (No Upfront, Pay as you go)
    Do NOT check "1-year Reserved" or "3-year Reserved" yet.
  • This displays your true zero-commitment, pay-only-for-what-you-use monthly expense.
