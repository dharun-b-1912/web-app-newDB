6. Network Architecture & NAT Gateway Economics

A. Subnet Isolation Strategy

• Public Subnets (10.0.1.0/24, 10.0.2.0/24): Application Load Balancers, Internet Gateways, NAT Gateways.
• Private App Subnets (10.0.10.0/24, 10.0.20.0/24): ECS Fargate container tasks, Lambda VPC interfaces.
• Private Isolated DB Subnets (10.0.100.0/24, 10.0.200.0/24): RDS PostgreSQL and ElastiCache. Zero internet route. Complete protection against external intrusion.

B. NAT Gateway Cost Optimization (VPC Endpoints)

• The Risk: NAT Gateways charge $0.045/hr + $0.045/GB. Downloading large employee files or DB backups through NAT can cost hundreds of dollars at scale.
• The FinOps Fix: Deploy AWS Gateway VPC Endpoints for Amazon S3 and DynamoDB. These endpoints are 100% FREE, routing all storage traffic privately inside AWS, saving ₹10,000 to ₹38,000/month at scale.

RDS vs Aurora PostgreSQL FinOps Decision

• Amazon RDS PostgreSQL: Predictable gp3 SSD storage cost, synchronous Multi-AZ failover (60-120s), perfectly suited for 1k to 100k users.
• Amazon Aurora Serverless v2: Instant scaling up to 128 ACUs, faster failover (< 30s), but costs ~40% more ($890/mo vs $580/mo).
• Verdict: Amazon RDS PostgreSQL is the FinOps winner for all scales up to 100k employees.

16. Connection Pooling & Biometric LAN Architecture

PostgreSQL Connection Pooling (RDS Proxy)

• At 100k users, 8 ECS tasks can open up to 200 concurrent sockets.
• RDS Proxy ($43/mo) pools connections, prevents connection starvation, and preserves active mobile sessions during database failovers.

Factory Biometric Edge Gateway Architecture

• Factory ZKTeco devices sit inside private LANs. Local forwarder polls devices via node-zklib, buffers punches in SQLite, and streams HTTPS batches to Amazon SQS.
• Guarantees zero punch loss even during factory internet cuts.
